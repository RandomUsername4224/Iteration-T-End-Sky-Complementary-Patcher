# Iteration T

Iteration T adds an animated planetary system, star field, black hole and accretion disc to the End sky of supported Complementary-based shader packs.

### Requirements

- Windows 10 or later for the included graphical launcher.
- Python 3.11 or newer with Tcl/Tk support.
- No third-party Python packages are required.

Official Python downloads: https://www.python.org/downloads/windows/

## Compatibility

The installer is designed for:
- Complementary Reimagined r5.9.3.
- Euphoria Patches 1.10.5 applied to Complementary Reimagined r5.9.3.

Use an original, unmodified source pack. The installer creates a new output and does not modify the selected source.

## What it adds

- Animated ringed planet and star field.
- Black hole, accretion disc and gravitational lensing.
- End lighting and purple sky-colour controls.
- Custom End shadow handling.
- Support for the standard and Euphoria-patched source packs.

## Installation

1. Download and extract the installer ZIP.
2. Open the extracted `Iteration T` folder.
3. Run `Start Iteration T.bat`.
4. Select your original Complementary or Euphoria shader pack.
5. Select the newly generated shader pack in Minecraft.

See the [user guide](USER-GUIDE.md) for detailed setup, settings and troubleshooting.
