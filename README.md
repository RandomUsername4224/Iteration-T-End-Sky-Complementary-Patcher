# Complementary End Skybox Patcher

**Adds the Iteration T End skybox to Complementary Reimagined.** This project is a patcher for supported Complementary-based shader packs; it is not the Iteration T shader pack itself. Iteration T is the source of the End-sky effects being integrated.

## Download

**[Download Complementary-End-Skybox-Patcher.zip](https://github.com/RandomUsername4224/Iteration-T-End-Sky-Complementary-Patcher/raw/refs/heads/main/downloads/Complementary-End-Skybox-Patcher.zip)**

Upload the patcher ZIP to the repository's `downloads/` folder to activate the direct download link above.

[Full user guide](USER-GUIDE.md) · [Attribution and third-party notices](ATTRIBUTION.md)

## What it adds

- Iteration T's animated ringed planet and stars in the End sky.
- A black hole, accretion disc and gravitational lensing.
- End lighting, brightness and purple-colour controls.
- Custom End shadow handling, including off-screen shadow casters.
- Support for Complementary Reimagined r5.9.3 and Euphoria Patches 1.10.5 applied to that release.

## Requirements

- Windows 10 or later for the graphical launcher.
- Python 3.11 or newer with Tcl/Tk support.
- No third-party Python packages are required.

Download Python from the [official Windows downloads page](https://www.python.org/downloads/windows/). See the user guide for installation instructions, supported inputs, settings and troubleshooting.

## Install

1. Download and extract the patcher ZIP.
2. Run **Start Patcher.bat** from the extracted **Complementary End Skybox Patcher** folder.
3. Select an original compatible Complementary shader-pack ZIP or folder.
4. Select the generated `-End-Skybox` shader pack in Minecraft.

The patcher creates a new copy and does not modify your source pack.
